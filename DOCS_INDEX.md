## 🚀 Standard Setup Path

### For First-Time Setup (1-2 hours)

1. **10 mins** - Read [`QUICK_START.md`](./QUICK_START.md)
2. **30 mins** - Set up accounts:
   - Supabase
   - ElevenLabs
   - Google Cloud (Gemini)
   - Resend
   - Vercel (optional)
3. **10 mins** - Create `.env.local` with all keys
4. **10 mins** - Run `npm install && npm run dev`
5. **20 mins** - Test all flows
6. **30 mins** - Read [`SETUP.md`](./SETUP.md) for details
7. **20 mins** - Explore code and customize

### For Deployment (1 hour)

1. **10 mins** - Review deployment checklist in [`RESOURCES.md`](./RESOURCES.md)
2. **15 mins** - Test all flows locally
3. **10 mins** - Push to GitHub
4. **15 mins** - Connect to Vercel and add env vars
5. **10 mins** - Deploy and test
6. **Optional** - Set up monitoring
