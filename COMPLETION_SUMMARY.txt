================================================================================
                       QUICK START GUIDE
================================================================================

STEP 1: INSTALL (2 minutes)
  $ npm install

STEP 2: GET API KEYS (10 minutes)
  1. Supabase (database) - https://supabase.com
  2. ElevenLabs (voice AI) - https://elevenlabs.io
  3. Google Gemini (vision) - https://ai.google.dev
  4. Resend (email) - https://resend.com

STEP 3: CREATE .env.local (1 minute)
  NEXT_PUBLIC_SUPABASE_URL=your_url
  NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
  NEXT_PUBLIC_ELEVENLABS_API_KEY=your_key
  NEXT_PUBLIC_ELEVENLABS_AGENT_ID=your_agent_id
  NEXT_PUBLIC_GEMINI_API_KEY=your_key
  RESEND_API_KEY=your_key

STEP 4: RUN (1 minute)
  $ npm run dev
  Visit: http://localhost:3000

TOTAL TIME: ~15-20 minutes for first run
